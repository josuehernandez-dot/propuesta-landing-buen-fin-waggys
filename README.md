# Waggy's · Buen Fin 2026 (vista de propuesta)

Versión estática de la landing para enseñarla al cliente. El carrito y la fecha son simulados.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo (por ejemplo `waggys-buen-fin`). Puede ser público o privado con GitHub Pro.
2. Sube **el contenido de esta carpeta** a la raíz del repo: `index.html`, `.nojekyll` y la carpeta `assets/`.
3. *Settings → Pages → Build and deployment*: Source **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
4. En 1–2 minutos queda en `https://<usuario>.github.io/waggys-buen-fin/`.

## Ver cada fase

Usa el panel "Simular fecha" o comparte el link directo:

- `?fase=pre` antes del 13 de noviembre
- `?fase=buen-fin` 30%
- `?fase=extension` 20%
- `?fase=black` Black Weekend
- `?fase=ended` después del 30 de noviembre

Las fotos y precios vienen de waggys.pet (octubre 2026). La página tiene `noindex` para que no aparezca en Google.
